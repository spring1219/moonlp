# `moonlp` 项目申报书

## 1. 项目名称
**moonlp**（纯 MoonBit 线性规划与混合整数规划求解库）

## 2. 项目简介
`moonlp` 是一个零外部依赖的纯 MoonBit 运筹优化库，提供线性规划（LP）和混合整数线性规划（MILP）建模与求解能力，支持两阶段单纯形法、Bland 防退化循环、分支定界求解、对偶影子价格与灵敏度分析、KKT 强对偶校验，以及工业标准 CPLEX `.lp` 与 Netlib `.mps` 文件读写。

## 3. 项目方向与通用性说明
- **项目方向**：基础工具库 / 科学计算与运筹优化。
- **通用性**：目前 `mooncakes.io` 已有线性代数与 SAT 库，但缺少独立的 LP/MILP 求解器。`moonlp` 不依赖平台 FFI 或 C 库，可编译到 Wasm、JS、Native 全后端，在浏览器、边缘节点和服务端均可直接嵌入使用。

## 4. 预期使用场景
1. **供应链排产与库存调度**：在产能、需求和库存持有成本约束下，求解多周期最小成本生产计划，并利用对偶影子价格评估瓶颈产能的边际收益。
2. **资源分配与网络流优化**：用于任务指派、设施选址、网络最大流/最小费用流、带宽或算力配额调度等组合优化问题。
3. **规则求解与交互式前端工具**：编译为 Wasm 后可在网页端本地运行排班表生成、营养/配方混料优化、游戏数值平衡验算及数独类约束求解，无需后端算力服务。

## 5. 拟实现的核心功能
- **代数建模 DSL**：支持 `Minimize`/`Maximize`、连续/整数/0-1 变量、任意上下界与自由变量、独立可行性验证。
- **LP 求解与后验分析**：两阶段单纯形法（Dantzig 选元 + Bland 防循环）、对偶影子价格、检验数、RHS 扰动灵敏度分析与 KKT 强对偶证明。
- **MILP 求解与预处理**：Presolve 单变量界收紧与冗余行消除、Best-Bound 分支定界（后续迭代 Dual Simplex 热启动、Gomory 割平面及 Netlib 基准测试）。
- **标准格式互操作**：CPLEX `.lp` 与 Netlib `.mps` 双向解析与导出。

## 6. 原创 / 移植说明
**原创项目**（Apache-2.0），所有求解算法、数据结构与解析器均从零以 MoonBit 编写，非已有代码库直接翻译移植。

## 7. 参考开源项目说明
本项目非移植项目。在建模 API 风格和标准算例选型上参考了以下公开项目与标准文档：
- `microlp`（https://github.com/Specy/microlp ，MIT 协议）：参考其轻量化纯代码建模接口思路；
- `good_lp`（https://github.com/rust-or/good_lp ，MIT 协议）：参考其变量/约束表达式组织方式。
